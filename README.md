# 紙頁 PDF工具

[下載 Windows 分享包（約 182 MB）](https://github.com/evatsai0108-dev/paperdesk-downloads/releases/download/windows-v1.0.0-beta.1/Paperdesk-1.0.0-beta.1-Windows-x64-Share.zip)

版本：1.0.0-beta.1，Windows x64 測試版。

## 安裝與使用

下載 ZIP 並解壓縮，執行資料夾中的 `Paperdesk-1.0.0-beta.1-Windows-x64-Setup.exe`，依畫面完成安裝。之後從桌面「紙頁 PDF工具」捷徑開啟，拖入 PDF 即可轉成 Word；其他轉檔、合併、切割、旋轉、編輯及浮水印功能可從左側選單選擇。

分享包包含安裝程式、安裝與使用說明、驗收報告及校驗碼。轉檔在本機執行，使用者不需帳號、API 金鑰、Node.js 或 Python；開啟產生的 Office 檔案需要相容的編輯軟體。

## 驗收與使用範圍

同一份安裝包已通過 Windows Server 2025 x64 與 Windows 11 ARM64 的 x64 相容模式驗收。每個環境各通過 16 項核心案例、11 組桌面流程，以及實際安裝、桌面與開始功能表捷徑啟動、解除安裝。詳細內容見 [驗收結果](VALIDATION.md)。

Windows 10 與 Intel／AMD 的 Windows 11 尚未另做實機驗收。低解析掃描、小字、注音及複雜版面仍需核對原稿。此版尚未使用發行者憑證數位簽章，Windows 可能顯示發行者未驗證提示。
